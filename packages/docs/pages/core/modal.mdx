    ```vue
    <script setup lang="ts">
      import { ModalManager, Button } from '@vue-material/core'

      function openModal() {
        ModalManager.open({
          title: 'Basic Modal',
          content: 'This is a simple modal dialog.',
          actions: [
            { label: 'Close', onClick: (utils) => utils.close() }
          ]
        })
      }
    </script>

    <template>
      <Button @click="openModal">Open Modal</Button>
    </template>
    ```

  </CodeHighlight>

> **Note:** To use `ModalManager`, you must include `<Modal.Provider />` at the root of your application (e.g., in `App.vue`).

## Props

`title?`: string | Component

- The title of the modal.

`content?`: string | Component

- The content of the modal.

`actions?`: { label: string, onClick: (utils) => void, variant?: string, disabled?: boolean }[]

- Array of action buttons.

`icon?`: string | Component

- Icon to display at the top.

`closeable?`: boolean

- Whether the modal can be closed by clicking outside or pressing escape.

`fullScreen?`: boolean

- Whether the modal is fullscreen.

`width?`: string

- Width of the modal.
