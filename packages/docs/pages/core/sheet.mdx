> **Note:** Similar to `Modal`, `Sheet` can be controlled via `SheetManager` and requires `<Sheet.Provider />` in the app root.

## Directions

Sheets can appear from `left`, `right`, `top`, or `bottom`.

## Props

`title?`: string | Component

- Title of the sheet.

`content?`: string | Component

- Content of the sheet.

`direction?`: 'left' | 'right' | 'top' | 'bottom'

- The edge from which the sheet appears.
- Default: `left`

`size?`: number

- Initial size of the sheet (width for left/right, height for top/bottom).

`resizable?`: boolean

- Whether the sheet is resizable by dragging.

`closeable?`: boolean

- Whether the sheet can be closed.
