```vue
  <Text variant="body-medium">Body Medium</Text>
</template>
```

  </CodeHighlight>
</Preview>

### Props (Text)

`variant?`: TypographyStyle

- The typography style to apply. e.g. `display-large`, `body-medium`.

`lines?`: number

- Maximum number of lines to display.

## Awaited Text

Text that displays a loader or placeholder while waiting for a value (Promise).

<Preview>
  <PreviewFrame height="100">
    <Box p="#md">
      {/*
        NOTE: Passing a promise inline in MDX JSX might be tricky for serialization.
        We'll just show the static state or a simulated one if possible,
        or just the code block if the live preview is too complex.
        Let's try a simple string first to ensure it renders.
      */}
      <AwaitedText value="Loaded Value">
        Loading...
      </AwaitedText>
    </Box>
  </PreviewFrame>

  <CodeHighlight>

```vue
<script setup lang="ts">
  import { AwaitedText } from '@vue-material/core'
  const myPromise = new Promise(r => setTimeout(() => r('Loaded!'), 2000))
</script>

<template>
  <AwaitedText :value="myPromise">
    Loading...
  </AwaitedText>
</template>
```

  </CodeHighlight>
</Preview>
