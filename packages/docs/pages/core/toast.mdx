## Usage

<Preview>
  <PreviewFrame height="150">
    <Flex align="end" justify="center" style={{height: '100%', paddingBottom: '20px'}}>
        <Toast
          class="static"
          message="Notification Message"
        />
    </Flex>
  </PreviewFrame>

  <CodeHighlight>
    ```vue
    <script setup lang="ts">
      import { ToastManager, Button } from '@vue-material/core'

      function showToast() {
        ToastManager.open({
          message: 'Notification Message'
        })
      }
    </script>

    <template>
      <Button @click="showToast">Show Toast</Button>
    </template>
    ```

  </CodeHighlight>
</Preview>

> **Note:** Requires `<Toast.Provider />` in the app root for `ToastManager` usage.

## Props

`message?`: string | Component

- Message to display.

`icon?`: string | Component

- Icon to display. Defaults to favicon if not provided.

`variant?`: 'short' | 'expanded'

- Layout variant.
- Default: `short`
