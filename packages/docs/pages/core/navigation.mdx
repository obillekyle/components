## Props (Navigation)

`labels?`: 'always' | 'active' | 'hidden'

- Label display mode.
- Default: `always`

`active?`: number

- Index of the active item.

## Props (Navigation Item)

`icon`: string | Component

- Icon to display.

`label`: string

- Label text.

`badge?`: string | number

- Badge content.
