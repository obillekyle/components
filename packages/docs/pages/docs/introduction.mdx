## Welcome

Vue Material Components is a Vue 3 component library inspired by Google's Material Design.

## Features

- **Material Design 3**: Fully compliant with MD3 specs.
- **Vue 3**: Built for Vue 3 using Composition API.
- **TypeScript**: Written in TypeScript with full type support.
- **Customizable**: Theming system to match your brand.
