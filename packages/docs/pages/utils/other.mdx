## Frame Queue

`FrameQueue` is a utility for scheduling tasks to run on the next animation frame, essentially a manager for `requestAnimationFrame`.

<Preview>
  <CodeHighlight>

```ts
import { FrameQueue } from '@/utils/other/frame-queue'

function update() {
  console.log('Frame update')
}

// Add task
FrameQueue.add(update)

// Remove task
FrameQueue.remove(update)
```

  </CodeHighlight>
</Preview>

## Image Utilities

### `getAverageColor(source: string | HTMLImageElement): Promise<string>`

Calculates the average color of an image.

<Preview>
  <CodeHighlight>

```ts

const color = await getAverageColor('/path/to/image.jpg')
```

## Translation

### `translate(x: number, y: number, unit?: string): string`

Generates a CSS transform string.

<Preview>
  <CodeHighlight>

```ts
import { translate } from '@/utils/other/translate'

const style = translate(10, 20) // "translate(10px, 20px)"
const stylePerc = translate(50, 50, '%') // "translate(50%, 50%)"
```

  </CodeHighlight>
</Preview>
